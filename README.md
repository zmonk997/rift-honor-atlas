# 峡谷档案

英雄联盟五路选手荣誉与生涯数据查询。支持位置筛选、ID/中文昵称搜索、荣誉明细、年度轨迹和双选手六维图对比。

数据快照：2026-11-16。包含102位选手、1015条荣誉记录；95位有公开比赛聚合数据，87位六维完整。每位选手的统计来源和缺失项均在页面内标明。

荣誉来源：https://tieba.baidu.com/p/11198807139?see_lz=1

比赛统计来源：Games of Legends，各选手原始链接见 data.json。

本项目为静态网页，使用相对资源路径，无需账号即可查看。部署源为 main 分支根目录。分位只反映所选样本中的相对统计位置，不代表个人综合实力。
